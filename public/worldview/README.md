# 3D-карта «От атома до Вселенной»

Изолированный MVP внутри `public/worldview/`. Не меняет ЦУП и MAX-приложение.

## Что уже есть
- вращение, панорамирование и масштабирование 3D-сцены;
- кликабельные узлы;
- подсветка связей;
- три типа сущностей: масштабы, сквозные принципы, источники;
- фильтр по уровню доказательности;
- поиск по узлам и источникам;
- карточка узла с связанными сущностями;
- данные отделены от визуального движка (`data.js`).

## Принцип доказательности
1. **fact** — научный факт / устоявшаяся теория;
2. **model** — научная или системная модель;
3. **worldview** — мировоззренческая интерпретация;
4. **hypothesis** — гипотеза / требует проверки.

Наличие линии на карте не означает тождество механизмов. Она означает только зафиксированный тип связи, который должен иметь источник и уровень уверенности.
