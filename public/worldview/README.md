# Атлас понимания мира — v2

Главный экран больше не является свободным 3D-графом. Он построен как **познавательный маршрут**.

## Маршрут 01
**Вопрос:** «Что делает множество частей единым целым?»

Шкала:
атом → молекула → клетка → организм → экосистема → биосфера → Солнечная система → галактика → Вселенная.

Для каждого масштаба одинаковая рамка:
1. что является целым;
2. из каких частей оно состоит;
3. что связывает части;
4. что проходит через систему;
5. как сохраняется устойчивость;
6. какое новое качество возникает.

## Четыре слоя
- **Как устроено** — механизм;
- **Принцип** — сквозной системный вопрос;
- **Источник** — научная или библиотечная опора;
- **Смысл** — философский вопрос, явно отделённый от науки.

## Сквозные вопросы
Связь, граница, поток, обратная связь, мера, ритм, новое качество.

Важно: наличие одного и того же системного слова на разных масштабах **не означает одинаковый механизм**.
