# Бот «Офис АИ» · напоминания об оплатах

Сервис на Node 22 без npm-зависимостей. Читает Google Таблицу «Реестр платежей — Точка Притяжения», напоминает в чат MAX о платежах, принимает отметку «Оплачено» с фото чека и пишет строку в «Журнал оплат». Токены и ключи только в переменных окружения, в репозитории их нет.

## Что делает

- **Ежедневно в 09:00** (Europe/Simferopol) читает лист «Обязательства»: строки с «Напоминать» = Да, заполненным днём оплаты и «Суммой сейчас». Строки без суммы или дня пропускаются с записью в лог, бот на них не падает.
- **Платёж за месяц считается сделанным**, если в «Журнале оплат» сумма по этому ID с «За месяц» = 1‑е число текущего месяца ≥ «Сумма сейчас». Та же логика, что в формуле листа «Контроль по месяцам».
- **Напоминает** за 3 дня, накануне, в день оплаты и каждый день после срока (список дней «до» настраивается `REMIND_DAYS_BEFORE`, по умолчанию `3,1`). Формат: `Завтра: Аренда салона Top Thai Spa, 55 000 ₽, до 5-го. Платит: Бухотдел (р/с ООО)` плюс строка «Ответственный» из колонки L. Под каждым напоминанием кнопка **«Оплачено»**. Одно напоминание на обязательство в день, повторные запуски не дублируют.
- **«Оплачено»** → сумма (по умолчанию «Сумма сейчас» или «Другая сумма» текстом) → способ (Бухотдел (р/с ООО) / Личная карта / Наличные) → фото чека (или «Без чека») → строка в журнал: A сегодня, B ID, C под формулу, D 1‑е число месяца, E сумма, F способ, G «фото в MAX», H «отметил: Имя». Фото сохраняется в папку Drive «03 — БАНКИ · ОПЛАТЫ» как `ГГГГ-ММ-ДД__ID__Статья.jpg`. Если Drive недоступен, запись в журнал всё равно делается, бот предупреждает.
- **1‑го числа** присылает сводку за прошлый месяц: что оплачено, что нет, сколько ушло с личных карт.
- **Команды в чате:** `/статус` (текущий месяц), `/сводка` (прошлый месяц), `/напомнить` (разослать сейчас), `/отмена`, `/помощь`.
- **Этап 2 (выключен по умолчанию):** при заданном `STAGE2_FOLDER_ID` раз в N минут смотрит файлы с суффиксом `__MAX-` в папке, достаёт ИНН и сумму из текста, сопоставляет с «Обязательствами» и предлагает запись кнопкой «Подтвердить». Без подтверждения ничего не пишет. Текст сейчас читается только из Google Документов и text/*; PDF и картинки пропускаются (нужен OCR, его здесь нет).

Как пишется строка журнала: значения отправляются как есть (`valueInputOption=RAW`), даты в A и D — серийные числа Sheets, затем на новую строку копируются формула колонки C и формат A:H с первой строки журнала. Это не зависит от локали и не трогает существующие формулы; формула «Контроль по месяцам» видит в D настоящую дату.

## Файлы

| Файл | Назначение |
|---|---|
| `dates.js` | календарь Europe/Simferopol, серийные даты Sheets, разбор «55 000,00 ₽», «09.2026», «5-го» |
| `registry.js` | чистая логика: разбор листов, «оплачено», стадии напоминаний, тексты, сводка, сопоставление платёжек |
| `bot.js` | диалог «Оплачено», рассылка, расписание, запись в журнал и на Drive, этап 2 |
| `max.js` | клиент MAX Bot API (`platform-api2.max.ru`): `/updates`, `/messages`, `/answers` |
| `google.js` | сервисный аккаунт (JWT RS256), Sheets `values:batchGet/append`, `batchUpdate copyPaste`, Drive upload/list |
| `index.js` | запуск, `--check`, `--dry-run`, состояние в JSON |
| `../../tests/payments.test.mjs` | тесты без сети (запускаются в CI) |

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `MAX_BOT_TOKEN` | да | токен бота от MasterBot в MAX |
| `MAX_CHAT_ID` | да | id чата «Офис АИ» (бот должен быть участником); узнать: `--check` или из `bot_added` |
| `SPREADSHEET_ID` | да | id таблицы «Реестр платежей» (из адреса документа) |
| `GOOGLE_SERVICE_ACCOUNT_FILE` или `GOOGLE_SERVICE_ACCOUNT_JSON` | да | ключ сервисного аккаунта; таблица и папка чеков расшарены на его e‑mail |
| `DRIVE_RECEIPTS_FOLDER_ID` | для фото | id папки «03 — БАНКИ · ОПЛАТЫ» |
| `RESPONSIBLE_MAP` | нет | JSON: кого упоминать по колонке L, например `{"Бухотдел":{"username":"polina","name":"Полина"}}` |
| `MENTION_STYLE` | нет | `username` (по умолчанию, «@username») или `link` (`[Имя](max://user/ID)` с markdown) |
| `REMIND_AT`, `BOT_TZ`, `REMIND_DAYS_BEFORE` | нет | `09:00`, `Europe/Simferopol`, `3,1` |
| `STATE_FILE` | нет | путь к состоянию (`bot/payments/state/payments.json`, в git не попадает) |
| `STAGE2_FOLDER_ID`, `STAGE2_SUFFIX`, `STAGE2_SINCE`, `STAGE2_EVERY_MINUTES` | этап 2 | папка с платёжками, суффикс `__MAX-`, дата начала (RFC3339), период |

## Запуск

```bash
cd bot/payments
node index.js --check                       # бот MAX, чат, таблица и листы на месте, ничего не отправляет
node index.js --dry-run --date 2026-10-05   # кто получит напоминание в эту дату и сводка, без отправки
node index.js                               # рабочий режим: длинный опрос MAX + расписание
```

Перезапуск при падении: pm2 или systemd `Restart=always`. Состояние (курсор обновлений, кому напомнили, открытые диалоги) переживает перезапуск в `STATE_FILE`.

## Ворота согласования (только после «да» Алексея)

1. Создать сервисный аккаунт Google, выдать ему доступ редактора к таблице и к папке чеков, передать ключ на сервер (не в репозиторий и не в документы).
2. Создать бота в MasterBot, добавить в чат «Офис АИ», передать токен на сервер.
3. Merge в `main` и запуск в production.
4. Платные ресурсы не требуются: Sheets/Drive API и MAX Bot API бесплатны; хостинг — существующий сервер штаба.

## Проверка на копии таблицы (VERIFY)

1. Сделать копию таблицы, расшарить на сервисный аккаунт, указать её `SPREADSHEET_ID`, тестовый чат в `MAX_CHAT_ID`.
2. `node index.js --dry-run --date <день за 3 дня до оплаты>`: в списке есть нужное обязательство с текстом «Через 3 дня: …». Повторить для дня накануне, дня оплаты и дня после.
3. Запустить бота, `/напомнить`: сообщения приходят, у каждого кнопка «Оплачено», ответственный упомянут.
4. Нажать «Оплачено» → сумма → способ → фото. Проверить: в «Журнале оплат» новая строка с датой, ID, статьёй по формуле, «За месяц» = 1‑е число (отображается как `10.2026`), суммой числом, способом, «фото в MAX», «отметил: …». На листе «Контроль по месяцам» статус строки стал «Оплачено». Файл чека лежит в папке Drive.
5. Повторное «Оплачено» по тому же ID отвечает «Уже отмечено».
6. `/сводка` показывает прошлый месяц с суммой по личным картам.

## Что требует подтверждения на живом MAX

- Способ упоминания пользователя в сообщении бота: открытая документация SDK показывает только разметку markdown/html, синтаксис упоминаний в ней не описан, а dev.max.ru из среды разработки недоступен. По умолчанию бот пишет `@username`; при `MENTION_STYLE=link` пробует `[Имя](max://user/ID)`. Проверить на тестовом чате и оставить рабочий вариант.
- Срок жизни ссылки `payload.url` у фото: бот скачивает фото сразу после получения, поэтому риск минимален.
