# Контент-разведка AI Штаба

## Назначение

Модуль собирает публичные сигналы из YouTube Shorts, Instagram Reels и TikTok и переводит их в управляемый редакционный контур:

**найти → отобрать → транскрибировать → проверить факты → сформировать наш угол → подготовить сценарий → согласовать → опубликовать → измерить результат.**

Публикация не автоматизируется без прямого подтверждения владельца.

## Архитектура MVP

1. Внешний аналитический слой (сейчас vidIQ через ChatGPT) ищет трендовые ролики, выбросы относительно обычных просмотров автора, релевантные Reels/TikTok и при необходимости делает транскрипты, комментарии и покадровый разбор.
2. Результат переводится в безопасный снимок `live/content-intel.json`.
3. MAX-ЦУП читает сначала ветку `telemetry`, затем `main`, выбирая самый свежий валидный снимок.
4. В браузер попадают только публичные ссылки, открытые метрики и редакторские выводы. Токены, OAuth, приватные сообщения и внутренние секреты не публикуются.
5. Кнопка «Поставить в разбор» в MVP сохраняет решение локально на устройстве. Серверной записи в публичном статическом приложении нет.

## Основные метрики

- `views` — просмотры.
- `vph` — views per hour, скорость просмотров в час.
- `outlier` — во сколько раз ролик выше типичного уровня автора/канала.
- `priority` — редакторская оценка AI Штаба 0–100. Это не метрика платформы.

Приоритет учитывает соответствие направлениям Штаба, силу первого кадра/хука, воспроизводимость формата, наличие проверяемой фактологии и риск сенсационности.

## Направления

Базовые фильтры:
- Росток;
- РЭО Крым;
- РКО;
- Диалог о будущем;
- Точка притяжения.

Киноуроки, Юнармия и другие направления добавляются по мере появления сигналов.

## Схема снимка

`schema: content-intel-1`

Обязательные поля верхнего уровня:
- `visibility: public`;
- `generated_at`;
- `ttl_seconds`;
- `items[]`.

Минимальный item:
- `id`, `platform`, `title`, `url`;
- открытые `metrics`;
- `projects[]`;
- `hook`, `concept`, `format`, `why`, `risk`;
- `analysis.status`, `analysis.transcript_status`, `analysis.angle`, `analysis.reaction_idea`.

Нормализатор `public/content-intel.js` отбрасывает снимок, если он не помечен как публичный.

## Следующий этап

1. Сделать обновление радара регулярным.
2. Для карточек с приоритетом ≥ 90 автоматически запрашивать транскрипт/сценовый разбор.
3. Добавить фактчек и ссылки на первоисточники.
4. Вынести общую очередь разбора из localStorage в защищённый слой.
5. После публикации подтягивать собственные метрики каналов: удержание, досмотры, сохранения/репосты, комментарии, прирост подписчиков.
6. На этой основе корректировать вес редакторского `priority`.
